**TECHNOLOGY = Python · pandas · SQL · databases · Excel · Jupyter · AI tools.**

Use this domain when the interviewer is testing **technical aptitude and how comfortably you learn and use tools**.

## Technology | What technical tools are you comfortable using?

Connect the tool to a task: **Python/pandas for data work, SQL for querying databases, Excel for analysis and checking, Jupyter for exploratory work**.

## SQL | Why use SQL or a database instead of only spreadsheets?

A database is better when the data becomes **large, structured, repeatable or joined across tables**. SQL gives a clear way to query, filter, aggregate and join that data.

## Data Workflow | How do Python, pandas and SQL fit together?

**SQL/database stores and queries the structured data; pandas brings selected data into a DataFrame for analysis; Python is the wider programming language; Jupyter is the interactive working environment.**

## Debugging | What do you do when code or a technical process fails?

Read the error, reproduce it, reduce the problem, inspect inputs and data types, test assumptions one at a time and keep a record of the fix.
