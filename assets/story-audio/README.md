# Published story narration

Upload one MP3 per story here through GitHub's **Add file → Upload files** and commit to the default branch. Name recordings `story-01.mp3` through `story-10.mp3` in the same order as the Stories page.

After publishing, the Stories page automatically uses the corresponding MP3 instead of browser text-to-speech for that story. Replacing a file with the same name changes the narration for all visitors after deployment (browser cache may need refresh).

Never include access tokens or private recordings in this public repository.
