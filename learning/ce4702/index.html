Learning path

FOUNDATION

Lab 01 · Data types are contracts

Primitive vs reference data, parsing text, validation, boolean decisions and why representation matters.

OBJECTS

Lab 02 · Classes, state & invariants

Constructors, getters/setters, encapsulation and testing valid object state.

OOP

Lab 03 · Inheritance & polymorphism

Superclass/subclass design, overriding, abstract methods and dynamic dispatch.

ROBUSTNESS

Lab 04 · Exceptions & bad input

Design for failure rather than assuming every input is correct.

INTERFACES

Lab 05 · GUI & events

Event-driven thinking, Swing components, layout and use-case testing. Source plus captured runs.

TEXT DATA

Lab 06 · Strings & regular expressions

Patterns, parsing and validation of structured text.

DATA PIPELINE

Lab 07 · Files & CSV

Read, parse, structure, summarise and write data. This is the bridge to later data analysis.

ALGORITHMS

Lab 08 · Search & sort

Linear/binary search, selection/insertion sort and explicit test cases.

RECURSION

Lab 09 · Problems that call themselves

Factorial, Fibonacci and recursive decomposition.

COMPLEXITY

Lab 10 · Big-O & capstone

Move from “it works” to “how does the cost grow?” and combine the module in a final public project.

What makes this different from ordinary revision?

Every lab will contain four kinds of evidence: conceptual explanation, runnable Java, tests/output, and my own reflection. Lecturer examples remain source material; they are not represented as my code.

Cloud workflow

Open the Codespaces link, then use the terminal. For Lab 01:

cd learning/ce4702/code/lab01
javac DataTypesLab.java
java DataTypesLab

The repository is the permanent record. Codespaces is the temporary computer. GitHub Actions recompiles the published lab automatically whenever the Java source changes.
