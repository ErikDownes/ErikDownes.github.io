### How to use this site

This site is designed to be **used actively, not just read**. On practice pages, you can record an answer, listen back to it and try again. Most interview answers only need a clear core response; follow-up questions can then take the conversation further.

A useful practice loop is:

**Read → hide → retrieve aloud → listen → check → try again.**

Double-clicking a section opens it in a focused view, making it easier to work with one part of a page at a time.

### The learning behind it

This approach is based on **metacognition** — learning how you learn — and **retrieval practice**. Reading creates familiarity; trying to produce an answer without looking requires active recall. The hesitation before an answer comes is useful because it shows what has not yet been securely learned.

It also reflects **Lev Vygotsky's Zone of Proximal Development**: working in the productive space where a task is not too easy, but not so difficult that it becomes overwhelming. The aim is to be stretched, but supported.

The site also uses ideas from **Dual Coding Theory**, associated with **Allan Paivio**, by pairing verbal explanations with visual representations where they genuinely help. This connects with **Cognitive Load Theory** and the **split-attention effect**: related information should be kept together where possible so the learner is not forced to divide attention unnecessarily.

The recorder itself is not dual coding; its main value comes from **retrieval, repetition, self-monitoring and feedback**.
